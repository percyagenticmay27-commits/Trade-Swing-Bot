# Security Policy

## Purpose

This repository is intended solely for paper trading research and software development.

## Scope

- No real-money trading
- No brokerage execution
- No Robinhood order placement
- No automated buying or selling

## Reporting

Please report security vulnerabilities through GitHub Issues or a private disclosure channel if one is established.

## Project Safety

The repository is designed to generate research, analytics, simulations, and reports only.
All production changes should maintain paper_trade_mode=True.
