# Contributing

Thank you for contributing.

## Project Scope

This repository is a paper-only swing trading research system.

Contributions must:

- Preserve paper_trade_mode=True
- Never implement live trade execution
- Never integrate brokerage order placement
- Never add Robinhood execution
- Include unit tests for new modules
- Favor modular Python architecture
- Produce reports (CSV, JSON, Markdown) rather than live actions
